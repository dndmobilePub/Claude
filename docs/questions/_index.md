# 질문 모음

> 작업 중 생긴 질문(자료에 없거나, 해석이 필요하거나, 원본끼리 다른 것)을 한곳에서 관리한다.
> 질문은 원본별 파일에 한 줄씩 적고, 이 파일의 "현황"은 `build-index` 훅이 자동 생성한다. 직접 고치지 않는다.
> 양식: `templates/questions.md`
> IMPORTANT: 현황 표는 전체를 읽지 말고 필요한 대상(화면 ID 등)·확인 대상 행만 검색한다. (토큰 절감)

## 1. 어느 파일에 적나
질문이 **어디에서 생겼는지**로 정한다. 하나의 질문은 한 파일에만 적는다.

| 파일 | source | ID 앞부분 | 적는 질문 |
|---|---|---|---|
| `ia.md` | ia | Q-IA | IA를 읽다 생긴 것: 빈·중복 화면 ID, 형식이 다른 ID, 도메인 대응이 없는 값, 해석할 수 없는 일정 표시 |
| `plan.md` | plan | Q-PL | 기획서(Figma 설계서·PPT) 내용: 정책·문구·데이터가 없거나 해석이 필요한 것, Figma 설계서와 PPT가 다른 것 |
| `design.md` | design | Q-DS | Figma 디자인: 상태 디자인 없음, 대응 토큰·컴포넌트 없음, 변수 이름 문제, 프레임 크기 |
| `spec.md` | spec | Q-SP | 플로우·명세·퍼블 작업 중 생긴 것 가운데 위 셋에 속하지 않는 것, 원본끼리 다른 것(IA와 기획서, 기획서와 디자인) |

- 파일이 없으면 첫 질문이 생길 때 `templates/questions.md`로 만든다. (frontmatter `source`·`prefix`를 위 표대로)

## 2. 칸 쓰는 법
| 칸 | 값 |
|---|---|
| ID | `<ID 앞부분>-<3자리 번호>`. 파일 안에서 이어서 붙이고 다시 쓰지 않는다. (예: Q-PL-012) |
| 대상 | 화면 ID, 컴포넌트 이름, 도메인 키, 또는 `공통` |
| 출처 위치 | 질문이 생긴 곳. 예) `IA!E12`, `기획서 Figma 노드 12:34`, `PPT 슬라이드 7`, `docs/screens/<화면ID>.md 6번` |
| 질문 | 한 문장. 선택지가 있으면 함께 적는다 |
| 확인 대상 | 기획 / 디자인 / 개발 (프로젝트에서 다른 담당을 쓰면 예외 섹션에 적는다) |
| 차단 | 예 / 아니오. "예" = 답 없이는 명세 확정·퍼블을 할 수 없음 |
| 상태 | 미답변 / 보류 / 가정 / 확정 |
| 답 | 확정이면 답, 가정이면 가정한 내용, 보류면 보류 이유 |
| 반영 위치 | 답을 반영한 문서 경로(예: `docs/screens/<화면ID>.md`). 반영할 곳이 없으면 `반영 없음` |

## 3. 기록 규칙
- IMPORTANT: 답과 상태는 그 질문 줄에서만 바꾼다. 다른 문서에 질문·답을 복사하지 않고 ID로만 가리킨다.
- IMPORTANT: 자료로 답할 수 없는 것을 지어내지 않는다. 질문으로 남긴다.
- 질문이 생기면 작업을 이어가기 전에 한 번에 묶어 사용자에게 묻는다. 답을 받으면 그 자리에서 상태를 "확정"으로 바꾸고 반영한다.
- 답을 받지 못하면 상태를 "미답변"으로 두고, 차단 여부를 정한다.
- **가정**: 답을 기다리는 동안 임시 값으로 진행하는 것. 사용자가 가정을 허락한 경우에만 쓴다.
  - 가정한 값을 쓴 문서에는 그 자리에 `가정(Q-ID)`를 붙인다. (예: `최대 10건 가정(Q-PL-012)`)
  - 퍼블 완료 보고에 가정 목록을 반드시 적는다.
  - IMPORTANT: 차단 "예"인 질문은 가정으로 진행하지 않는다.
- **확정**: 답을 반영 위치 문서에 반영한 뒤 상태를 바꾼다. 문서에 남은 `가정(Q-ID)` 표시는 확정한 값으로 바꾸고 지운다.
- 줄을 지우지 않는다. 필요 없어진 질문은 상태 "확정", 답 "질문 취소: <이유>", 반영 위치 `반영 없음`으로 닫는다.

## 4. 작업과의 연결
| 작업 | 질문 확인 |
|---|---|
| 화면 명세 확정 점검 | 대상이 이 화면 ID이고 차단 "예"인 질문이 모두 확정이어야 한다 |
| 화면 퍼블 시작 | 대상이 이 화면 ID인 열린 질문(미답변·보류·가정)을 먼저 확인한다. 차단 "예"가 열려 있으면 멈춘다 |
| 화면 퍼블 완료 보고 | 이 화면의 가정 목록과 열린 질문 수를 적는다 |
| 현황 확인 | `docs/ui-flow/_index.md` 화면 맵의 "열린 질문" 칸 |
