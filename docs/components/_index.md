# 컴포넌트 명세 인덱스

> 컴포넌트 명세는 `templates/component-spec.md`로 작성해 이 폴더에 `<컴포넌트명>.md`로 저장한다.
> 기본 컴포넌트의 값은 Figma가 원본이다. 화면에서 쓰는 컴포넌트는 모두 명세로 등록한다. 이미 코드에 있는 컴포넌트는 연결만 담은 짧은 명세(kind: 기존)로 등록한다.
> "연결 목록"(Figma 컴포넌트 세트 이름 → 코드 컴포넌트)은 각 명세의 `figma_name`에서 만든다. 화면 명세를 쓸 때 Figma 인스턴스 이름을 이 목록과 대조한다. (`docs/DESIGN.md` 4번)
> IMPORTANT: 현황은 전체를 읽지 말고 필요한 Figma 이름·컴포넌트 행만 검색한다. (토큰 절감)
> 아래 "현황"은 `build-index` 훅이 각 명세의 frontmatter에서 자동 생성한다. 직접 고치지 않는다.
